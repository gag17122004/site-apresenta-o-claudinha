# Do Zero ao Primeiro Pedido

Apresentação interativa em HTML puro sobre como montar e operar um e-commerce do zero — produto, plataforma, embalagem e logística.

Criada como substituto de PowerPoint para trabalho da disciplina de **Gestão de Pessoas** no curso de Contabilidade.

## Demo

Deploy via Vercel. Acesse pelo link gerado após o deploy.

## Estrutura

```
├── index.html       # Aplicação completa (single file)
├── vercel.json      # Configuração de deploy
└── README.md
```

## Conteúdo

| Seção | Tema |
|---|---|
| 01 | Por que e-commerce? |
| 02 | Escolhendo o produto |
| 03 | Escolhendo a plataforma |
| 04 | Embalagem & identidade |
| 05 | Logística & envio |
| 06 | Resumo |

## Técnicas utilizadas

- Glassmorphism
- Bento Grid
- Parallax scroll
- Cursor customizado
- SVG animado
- Box 3D em CSS puro
- Reveal on scroll via IntersectionObserver
- Contadores animados
- Micro-interactions no hover

## Deploy

Hospedado na Vercel via integração com GitHub. Push na `main` atualiza automaticamente.

## Tecnologias

HTML · CSS · JavaScript — sem frameworks, sem dependências.
